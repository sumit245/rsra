Summary (from docblocks)

A payment link is a shareable URL that will take your customers to a hosted

payment page. A payment link can be shared and used multiple times.

When a customer opens a payment link it will open a new

href="https://stripe.com/docs/api/checkout/sessions">checkout session to

render the payment page. You can use

href="https://stripe.com/docs/api/events/types#event_types-checkout.session.completed">checkout

session events to track payments through payment links.

Related guide:

href="https://stripe.com/docs/payments/payment-links/api">Payment Links API
